Privacy policy

Last updated: October 6, 2026. This policy describes the operator's Instagram DM assistance tool for the virtual/AI character Becky (@snowbeckyy).

The tool receives Instagram messages through Meta's official API. It processes message text, message identifiers and timestamps, Instagram account identifiers, usernames when available, and conversation history. It also stores owner-provided conversation notes, adulthood confirmation evidence, contact opt-outs, distress pauses, and review decisions. Attachment messages may be flagged for manual review; the current tool does not download their media.

Messages and related records are stored in databases on the operator's Windows PC, including local backups. A locally running Ollama model uses the conversation context to draft replies. The tool can import available prior conversation history through Meta's API. Shadow mode prepares drafts without sending. The operator can send an approved reply manually or, after testing and activation, enable automatic replies to ordinary nonsexual messages. Flagged or ambiguous messages require human review. Drafts may be incorrect. Becky is a fictional virtual/AI creator; automated replies are identified as automated.

Meta provides the Instagram API and message delivery. Cloudflare Tunnel or ngrok relays webhook traffic to the operator's PC. These services process data under their own terms and privacy policies. Conversation content is not sent to a paid hosted language-model API in this setup.

The operator uses these records to maintain conversation continuity, review drafts, respect contact opt-outs, and apply age and distress safeguards. The tool does not use distress as a sales signal. The operator does not sell data collected by this tool.

There is currently no automatic retention limit. Records remain on the operator's PC and in local backups until the operator removes them. Access tokens and app secrets are stored separately from drafts and are not published in the review workflow. No system can guarantee absolute security.

To request access, correction, or deletion of your conversation records, contact snow_becky87@yahoo.com or message @snowbeckyy on Instagram. Include your Instagram username so the operator can identify your records. The operator may need to verify that the request is from the account holder. Deletion requests cover the tool's local message history, lead notes, drafts, send/review records and backups; the operator cannot delete copies held independently by Meta, Cloudflare or ngrok through this tool. You can request no further contact; opt-out records are retained to respect that preference unless you request their deletion too.

This tool is intended for ordinary Instagram conversations. Adulthood must be confirmed before any adult-content promotion; promotion is disabled in this setup. If age evidence conflicts, the conversation is flagged for human review.

The operator will update this policy if the tool's processing changes. Questions: snow_becky87@yahoo.com.
